# Kiro 分析定位表：哪个功能去哪个 js 文件

基线：**Kiro 1.4.5 / agent 1.1.499 / bundle 15.2MB（2026-10-22）**。
IDE 安装根：`C:/Users/<user>/AppData/Local/Programs/Kiro/resources/app/`。
Kiro 升级后（agent 版本号变化）按本表逐行 grep 对账，输出差异即漂移点。

## 文件映射

| 功能域 | bundle 文件（相对安装根） | 已验证锚点（grep 计数为基线值） |
|--------|--------------------------|-------------------------------|
| Memory：memories.db / 注入 / 分页 | `extensions/kiro.kiro-agent/dist/extension.js` | `workspace-sessions`×1、`24e3`×1、`=75`×1、`USER_PREFERENCE`×11、`workspaceDirectory`×3 |
| Skills/Steering frontmatter 校验 | 同上 | `title-shape`×3、`title-too-long`×3、`store-full`×3、`badPageSize`×1 |
| MCP 合并（powers url 型转换） | 同上 | `powers.mcpServers`、`mcpServers:b.record(F6e),powers`、`"url"`×80 |
| 会话存储 / SessionMigration | 同上 | `V1SessionStore`×1、`encodeWorkspaceDir`、`._migration-`/`.migrated-`、`workspacePaths`（复数，仅 continuation 路径） |
| sandbox 三档枚举 | 同上 | `DEFAULT_BLOCKED`×1、`COMMON_DEPENDENCIES`×14、`DEFAULT_ALLOWED`×1 |

## 对账注意事项（实测踩过的坑）

1. **settings 键注册横跨两个 bundle**——kiro-agent 扩展只注册一部分，`startupMode`/`mcpApprovedEnvVars` 等在主 workbench。只搜扩展 bundle 会误报「键消失」。
2. **键名搜索顺序**：先搜全限定名（`kiroAgent.memory`），零命中改搜裸键名（`memory`）——registerConfiguration 是嵌套定义，全限定名常搜不到。
3. **常量是表达式拼装**：注入单条上限 1817 = `60+200*eJl+500+XYl+eni`，grep 字面量 `1817` 永远零命中；搜 `24e3`/`=75` 这类字面量。
4. **CLI（kiro-cli）不在 IDE 安装目录**，是独立程序，会话/配置另取证。
5. `~/.kiro/extensions/extensions.json` 是用户级扩展清单（可为空）；kiro-agent 是内置扩展，固定在安装根的 `resources/app/extensions/` 下。
